## Description

Replaces internal location IDs with readable English and Chinese names in Event Lookup.

## Installation instructions

1. Install SMAPI, Content Patcher, and Event Lookup.
2. Extract `EventLookupReadableLocations` into your game's `Mods` folder.
3. Launch through SMAPI. No configuration needed.

## Main features

- Readable names for vanilla locations, Ginger Island, and locations from multiple expansion mods.
- English and Chinese translations.
- Expansion mods are optional; install only the ones you play.

## Requirements

- SMAPI 4.0.0+.
- Content Patcher 2.0.0+.
- Event Lookup 0.2.8+.
