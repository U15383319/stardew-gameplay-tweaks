## Description

Chop down normally protected trees in Pelican Town.

## Installation instructions

1. Install SMAPI.
2. Extract `DestroyableTownTrees` into your game's `Mods` folder.
3. Launch through SMAPI and use your axe on town trees.

## Main features

- Removes chopping protection from the supported town trees.
- Uses the game's normal tree-chopping behavior.
- No configuration needed.

## Requirements

- SMAPI 4.5.2+.
