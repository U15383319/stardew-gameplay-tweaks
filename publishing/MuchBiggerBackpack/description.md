## Description

Adds a larger backpack upgrade at Pierre's, with configurable capacity and price. Based on Bigger Backpack.

## Installation instructions

1. Install SMAPI and StardewHack.
2. Extract `MuchBiggerBackpack` into your game's `Mods` folder.
3. Launch through SMAPI. Edit the generated `config.json` to change capacity or price.

Before uninstalling, run `player_setbackpacksize 36` in the SMAPI console and save. Items in removed slots drop onto the ground.

## Main features

- Default upgrade: 48 slots for 50,000g.
- Set `BackpackSlots` to 48, 60, or 72.
- Set the upgrade price with `BackpackCost`.
- Resize inventory with the `player_setbackpacksize` console command.

## Requirements

- SMAPI 3.18.0+ (manifest minimum).
- StardewHack 6.0+.

Android/mobile is not supported.
