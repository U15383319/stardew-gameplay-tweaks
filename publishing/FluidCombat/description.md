## Description

Smoother combat with movement during attacks, attack cancellation, and held-button repetition.

## Installation instructions

1. Install SMAPI.
2. Extract `FluidCombat` into your game's `Mods` folder.
3. Launch through SMAPI. Configure with Generic Mod Config Menu or the generated `config.json`.

## Main features

- Move during melee attacks, weapon specials, and slingshot charging.
- Cancel melee attacks into specials and specials into attacks. Special cooldowns still apply.
- Hold buttons to repeat melee attacks or specials.
- Face the mouse cursor when starting melee attacks and specials.
- Adjust combat movement speed and toggle the movement hop.

Scythes are excluded. Cancellation and repetition apply only to melee weapons.

## Requirements

- SMAPI 4.5.2+.
- Optional: Generic Mod Config Menu.

English and Chinese configuration text included. Controller, multiplayer, and split-screen compatibility is unverified.
