# Combat Enhanced

Move while using melee attacks, weapon specials, and slingshots. Left-click attacks and right-click specials can cancel each other.

Requires SMAPI 4.5.2+. Generic Mod Config Menu is optional. English and Chinese translations are included.

Build a local ZIP from the repository root:

```powershell
.\scripts\pack.ps1 -Mod CombatEnhanced
```
