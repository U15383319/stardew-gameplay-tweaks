# Event Lookup Readable Locations

Readable English and Chinese location names for Event Lookup, covering vanilla Stardew Valley, Ginger Island, and multiple large expansion mods.

Requires SMAPI 4.0.0+, Content Patcher 2.0.0+, and Event Lookup 0.2.8+. This content pack needs no compilation or configuration.

Build a local ZIP from the repository root:

```powershell
.\scripts\pack.ps1 -Mod EventLookupReadableLocations
```
